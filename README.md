# AI Prompt Library — Meridian Property Partners

**A consultancy-style prompt library for workflow automation in residential property management.**

This repository is the version-history portfolio for my AI prompting assessment. It contains the 10 prompts in my library, each in its own file, plus a log documenting how key prompts were iterated and improved across multiple versions.

## What's in this repo

| Folder / File | What it contains |
|---|---|
| `/prompts/` | All 10 prompts in the library — one file each, with the prompt text, intended workflow, problem solved, automation potential, and risks/limitations |
| `ITERATION-LOG.md` | Version history (v1 → v2 → v3) for the four highest-risk/highest-value prompts, showing what changed at each step and why |
| `README.md` | This file |

## Business context

Meridian Property Partners is a residential property management agency managing ~800 properties for ~350 landlords, supported by 12 property managers. The prompt library targets the highest-volume, most repetitive written workflows: maintenance requests, rent arrears follow-up, inspection reporting, lease renewals, tenant enquiries, landlord reporting, complaint handling, compliance tracking, and vendor comparison.
